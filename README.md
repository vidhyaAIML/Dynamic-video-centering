
# 🎯 Dynamic Video Centering

This project detects a face from webcam and keeps it centered in real-time using OpenCV.

## 🚀 Features
- Real-time face detection
- Dynamic centering
- Zoomed face view
- Alert system

## 🛠️ Tech Used
- Python
- OpenCV
- Tkinter

## ▶️ Run

```bash
python my_face_app.py
